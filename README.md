# 📚 Case Study — HistoryUA

## 📌 Про проєкт

**HistoryUA** — це навчальний вебсайт, створений для допомоги у вивченні **історії України та підготовці до НМТ**.

Ідея проєкту виникла через бажання зробити вивчення історії більш **цікавим, зрозумілим та сучасним**. Хотілося відійти від звичайного подання великої кількості тексту та зробити інформацію більш наочною.

---

## 🎯 Context

Спочатку я хотіла створити сайт, який допомагав би **краще вивчати історію України під час підготовки до НМТ**.

Історія містить багато дат, подій, історичних діячів та іншої інформації, яку потрібно запам'ятати. Тому я вирішила представити цей матеріал у більш цікавому форматі.

Також я хотіла, щоб сайт виглядав **сучасно та відповідав стилю сучасних вебсайтів**, тому під час створення приділяла увагу дизайну, оформленню та візуальній подачі інформації.

---

## ❗ Problem

Під час підготовки до НМТ потрібно опрацювати велику кількість історичної інформації. Якщо весь матеріал подається просто великими блоками тексту, його може бути складніше сприймати та запам'ятовувати.

Тому основною проблемою було зробити подачу матеріалу **більш структурованою, наочною та цікавою**.

---

## 💡 Approach

Для вирішення цієї проблеми я створила багатосторінковий сайт із тематичними розділами.

У проєкті використовувалися:

* **HTML** — для створення структури сторінок;
* **CSS** — для стилізації та адаптивної верстки;
* **JavaScript** — для інтерактивних елементів;
* **зображення та відео** — для більш наочного представлення інформації.

Окремо я намагалася зробити **сучасний стиль сайту**, щоб він більше нагадував сучасний вебресурс, а не звичайний електронний підручник.

---

## 🛠️ Execution

Роботу над проєктом я виконувала поступово:

1. Визначила основну ідею та мету сайту.
2. Продумала структуру та основні розділи.
3. Створила HTML-структуру сторінок.
4. Додала CSS-стилізацію.
5. Зробила тематичні сторінки.
6. Додала зображення та відео.
7. Використала JavaScript для інтерактивних елементів.
8. Додала адаптивну верстку.
9. Перевірила роботу сторінок та виправила помилки.

---

## 🏆 Result

У результаті я створила **багатосторінковий навчальний сайт HistoryUA**, на якому інформація про історію України розподілена за окремими тематичними розділами:

* 🏛️ **Архітектура**
* 👤 **Діячі**
* 🗺️ **Карти**
* 📅 **Дати**

Сайт поєднує **навчальний матеріал, сучасний дизайн, зображення та інтерактивні елементи**.

---

## 📖 Takeaways

Під час роботи над HistoryUA я отримала практичний досвід створення **багатосторінкового frontend-проєкту**.

Я попрактикувала:

* HTML
* CSS
* JavaScript
* адаптивну верстку
* роботу із зображеннями та відео;
* створення навігації між сторінками;
* структурування великої кількості інформації;
* тестування та виправлення помилок.

Також я зрозуміла, що під час створення сайту важливо думати не тільки про код, а й про **зручність користувача, структуру інформації та її візуальне сприйняття**.
